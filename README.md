# BT Shop - Python E-Ticaret Uygulaması

## Proje Hakkında

BT Shop, Python ile geliştirilmiş basit bir konsol tabanlı e-ticaret uygulamasıdır. Kullanıcılar ürünleri görüntüleyebilir, sepetlerine ürün ekleyebilir, ürün çıkarabilir ve siparişlerini tamamlayabilirler.

Bu proje Python temel konularını uygulamak amacıyla geliştirilmiştir.

## Özellikler

* Ürün listeleme
* Kategori listeleme
* Sepete ürün ekleme
* Sepetten ürün çıkarma
* Stok kontrolü
* Sipariş tamamlama
* Siparişleri dosyaya kaydetme
* Hata yönetimi

## Kullanılan Python Konuları

* Listeler (Lists)
* Sözlükler (Dictionaries)
* Tuple
* Fonksiyonlar
* Döngüler (for, while)
* Koşullar (if, elif, else)
* Hata Yakalama (try-except)
* Dosya İşlemleri

## Proje Yapısı

* products → Ürün verileri
* cart → Sepet verileri
* store_info → Mağaza bilgileri
* show_products() → Ürünleri gösterir
* show_categories() → Kategorileri gösterir
* add_to_cart() → Ürün ekler
* remove_from_cart() → Ürün çıkarır
* show_cart() → Sepeti görüntüler
* checkout() → Siparişi tamamlar
* save_order_to_file() → Siparişi dosyaya kaydeder

## Kurulum

1. Python 3 kurulu olduğundan emin olun.
2. Proje dosyasını indirin.
3. Terminal veya komut istemcisini açın.
4. Proje klasörüne gidin.
5. Aşağıdaki komutu çalıştırın:

```bash
python main.py
```
